# SpMV
This project defines a C++ library that implements a `SparseMatrix` class and several child classes that use different storage formats.
The library provides sparse matrix-vector operators for each storage type.
The supported storage types are `DEN`, `COO`, `CSR`, `ELL`, and `JDS`.
